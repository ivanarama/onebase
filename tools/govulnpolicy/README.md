# Проверка уязвимостей

CI передаёт настоящий поток `govulncheck -json ./...` в `go run ./tools/govulnpolicy`.
Пустой, оборванный или невалидный поток и отсутствие сообщения config дают отказ.
Allowlist пуста: каждая достижимая находка блокирует проверку. Старый pin Excelize
`v2.11.1-0.20260728235842-f98df08a8f6a` больше не получает исключения GO-2026-6452.

Ветка использует принятые исправления из main: Excelize
`v2.11.1-0.20260930021559-01a9ff32fb3c`, mscfb 1.0.8, efp 0.0.2 и Go 1.26.10.
Публичные регрессии открывают синтетические повреждённые книги через импортер,
DSL, HTTP и печатный шаблон в ограниченных подпроцессах; проверяют отсутствие
паники, частичного результата и оставшихся временных файлов. Циклические формулы
читаются по сохранённым значениям без вычисления. Корректные книги совместимы.

Go 1.26.10 исправляет GO-2026-6809: известные скомпрометированные промежуточные
TLS-сертификаты отвергаются. Исправлять нужно цепочку у поставщика внешнего
сервиса; отключать проверку TLS нельзя. Новых исключений policy не требуется.
