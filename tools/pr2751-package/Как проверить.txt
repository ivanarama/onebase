OneBase для Windows x64 — тестовая сборка PR #2751, коммит 080b08e4
https://github.com/ivanarama/onebase/pull/2751

1. Распакуйте ZIP в отдельную папку. Откройте Start.cmd двойным щелчком.
   Скрипт создаст тестовую базу SQLite в этой папке и откроет лаунчер.
2. Выберите Windows-Auth-2751 и нажмите «Предприятие».
3. Откройте «Система → Администрирование → Пользователи → + Добавить».
   Создайте первого пользователя admin, задайте ему пароль и отметьте
   «Администратор». Войдите в базу под этим пользователем.
4. Создайте обычного пользователя operator. В списке пользователей откройте
   его «Карточку». Включите «Аутентификация Windows», вставьте имя учётной
   записи, которое выдаёт команда whoami в терминале Windows, и нажмите
   «Сохранить привязку».
5. Выберите «Система → Выйти», закройте окно базы и снова нажмите
   «Предприятие» в лаунчере. При выключенной 2FA база откроется без пароля.
   В «Система → О программе» строка «Пользователь» должна показывать operator.

Для последующих запусков используйте Start.cmd. Тестовая база и настройки
сохраняются рядом с программой. Домен для этой локальной проверки не нужен.

Проверка общего сервера с доменного компьютера описана в начале документа
https://github.com/ivanarama/onebase/blob/080b08e4130a4f3cf81a864e21a32a9abd0972f1/docs/features.md
