Проверка входа под учётной записью Windows в OneBase
Windows x64, PR #2751, исходный коммит @SOURCE_SHA@
https://github.com/ivanarama/onebase/pull/2751

1. Распакуйте ZIP в отдельную папку и запустите Start.cmd. Скрипт создаст
   тестовую базу SQLite рядом с программой и откроет лаунчер.
2. Выберите базу Windows-Auth-2751 и нажмите «Конфигуратор». Откройте
   «Меню → Пользователи». В новой базе нажмите «+ Добавить», задайте логин
   admin и пароль, оставьте флажок «Админ» и нажмите «Создать». Если у базы
   уже есть администратор, войдите под его учётной записью.
3. В том же списке создайте пользователя operator с паролем, сняв флажок
   «Админ». В строке operator нажмите «Аутентификация Windows».
4. Откройте терминал Windows и выполните whoami. В Конфигураторе включите
   «Аутентификация Windows», вставьте результат whoami в поле «Учётная
   запись Windows» и нажмите «Сохранить привязку». В строке operator должно
   появиться имя в формате ДОМЕН\пользователь или КОМПЬЮТЕР\пользователь.
5. Вернитесь в лаунчер и нажмите «Предприятие». База откроется под operator.
   При включённой 2FA подтвердите второй фактор. Откройте «Система →
   О программе» и проверьте, что в строке «Пользователь» указан operator.
6. Для проверки отключения выберите «Система → Выйти» и закройте окно базы.
   В Конфигураторе откройте привязку operator, нажав на имя Windows в его
   строке. Снимите флажок, сохраните и снова запустите «Предприятие».
   В тестовой базе появится обычная форма входа.

Для следующих запусков используйте Start.cmd из той же папки. На одном
Windows-компьютере эту проверку можно пройти и с локальной учётной записью.

Для общей базы на Ubuntu откройте Конфигуратор со стороны сервера базы.
В «Меню → Параметры базы → Доменный вход» укажите публичный HTTPS-адрес,
имя службы Kerberos (SPN), домен Kerberos и путь к keytab на сервере.
Сохраните параметры и перезапустите базу. Подготовка Ubuntu и проверка
с доменного компьютера описаны в инструкции к этой сборке.
https://github.com/ivanarama/onebase/blob/@SOURCE_SHA@/docs/ubuntu-domain-login.md
