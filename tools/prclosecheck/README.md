# Проверка закрывающих ссылок коммитов PR

Обязательный шаг `build` запускает:

```sh
go run ./tools/prclosecheck -event "$GITHUB_EVENT_PATH"
```

Инструмент читает тело PR, репозиторий и точные base/head SHA из JSON события
`pull_request`. Нужна полная история (`actions/checkout` с `fetch-depth: 0`).
Проверяются сырые сообщения коммитов `base..head`, включая merge-коммиты этой
ветки; достижимые из base коммиты, принесённые синхронизацией, исключаются.

Для каждой закрывающей ссылки коммита нужна отдельная обычная строка в теле PR,
например `Fixes #123` или `Closes owner/repository#456`. Поддерживаются девять
английских форм close/fix/resolve, регистр и двоеточие после слова, полные
GitHub URL. Номера из разных репозиториев различаются. Каждая ссылка объявляется
своей строкой; текст в коде и HTML-комментариях декларацией
не служит. В неоднозначной разметке безопаснее вынести декларацию в отдельный
абзац верхнего уровня. Открывающая строка fenced-блока с отступом или префиксом
списка/цитаты консервативно прекращает поиск новых деклараций: разместите все
декларации перед таким блоком. Ранее найденные декларации сохраняются. CDATA, инструкции обработки и
HTML-объявления сохраняют состояние до своего терминатора, включая пустые
строки. Обычные упоминания без закрывающего слова не проверяются.

Обычный HTML-тег (включая `div` и `details`), не завершённый на своей строке,
консервативно прекращает поиск новых деклараций. Это относится и к незакрытому
атрибуту в кавычках: пустая строка и символ `>` внутри кавычек не делают скрытый
текст видимой декларацией. Разместите декларации перед таким тегом; ранее
найденные сохраняются. Даже если тег закрывается на следующей строке, поиск
не возобновляется. Завершённые в одной строке теги сохраняют прежнее поведение;
у `pre`, `code`, `script`, `style` и `textarea` остаётся отдельный разбор до
закрывающего тега.

Markdown-ссылка с незавершённой на своей строке меткой, адресом или title
также прекращает поиск новых деклараций. У reference-definition (`[имя]: адрес`)
заголовок может начинаться на следующей строке: поиск продолжается только при
простом title, полностью завершённом на той же строке. Поддерживаются его
разделители `"…"`, `'…'` и `(…)`. Пустые строки, закрытие конструкции на следующих
строках и её незавершённость поиск не возобновляют. Ранее найденные декларации
сохраняются; перенесите все закрывающие декларации перед такой разметкой.
Простые inline-ссылки, завершённые на одной строке, с title или без него,
сохраняют прежнее поведение. Вложенные скобки, escape-последовательности и код/HTML внутри метки
ссылки консервативно не разбираются: они также могут остановить поиск.

Ошибка называет SHA коммита и полную ссылку. Если закрытие намеренное, добавьте
декларацию в тело PR; иначе уберите закрывающую фразу из сообщения коммита.
Отрицание или кавычки в сообщении не защищают от закрытия GitHub.
Редактирование тела PR повторно запускает CI. Отсутствующие обязательные данные
события (включая отсутствующее/null тело) и неполная история завершают проверку
ошибкой. Проверка выполняется и для PR только с документацией.

Регрессии вызывают CLI с настоящими Git-репозиториями. Исторические фикстуры:
сообщение `a6752329cd7279e3038910fec23e5aae09457a36` и точное тело PR #1639.
Вместе они должны отклоняться: сообщение содержит лишнее закрытие #1274.
