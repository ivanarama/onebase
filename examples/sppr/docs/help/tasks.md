# Задачи и маршрут статусов

Задача описывает работу по функции: тип (исследование, проектирование,
разработка, тестирование), приоритет, исполнителя, срок, оценку,
взаимосвязи с другими задачами (родитель, предшествующая, последующая).

Маршрут статусов: Новая → Принята → ВРаботе → НаПроверке → Выполнена,
с завершением в Принята/Выполнена. Перескок статуса отклоняется гейтом этапов,
просроченные задачи видны в отчёте «Просроченные задачи» и на главной
странице.

История переходов пишется в регистр «История статусов задач»: автор, старый и
новый статус, комментарий. Платформенная история этапов показывает переходы в
карточке документа.
