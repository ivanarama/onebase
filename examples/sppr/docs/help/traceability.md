# Трассировка

Объект метаданных — описание сущности конфигурации: тип (справочник, документ,
регистр, отчёт…), имя, путь к YAML-файлу, назначение, статус, статус контроля.
Реквизиты объекта перечислены в табличной части справочника.

Регистр «Трассировка» связывает функцию с объектом, файлом и коммитом.
Отчёт «Трассировка функции» показывает, какие файлы реализуют функцию, а отчёт
«Покрытие функций» — функции, для которых нет ни объектов, ни сценариев.
