# Мост метаданных целевого проекта

Проектная база описывает не только декомпозицию, но и то, чем целевой проект
собирается. Мост метаданных превращает описание конфигурации, выданное
`onebase describe`, в справочник «Объекты метаданных», табличную часть
«Реквизиты» и регистр «Трассировка». Объект, которого нет в описании целевого
проекта, в проектной базе не появляется: ручное перечисление файлов расходится
с реальностью при первом же рефакторинге.

Выгрузите описание целевого проекта:

```bash
onebase describe --project <целевой проект> > desc.json
```

Импортируйте его обработкой «Импорт описания»:

```bash
onebase procrun --project examples/sppr --sqlite <файл базы> --proc ИмпортОписания \
  --file Файл=desc.json --set Проект=<id проекта>
```

Из формы обработки поле «Описание целевого проекта (JSON)» принимает тот же
файл; параметр «Функция для трассировки импорта» указывает функцию, к которой
временным владельцем пишется трассировка. Совпадение ищется по имени и типу: регламентное задание и обработка с одним
именом остаются двумя объектами. Импорт идемпотентен: повторный прогон
добавляет только новые объекты, уже записанные объекты не перетираются,
назначенная проектировщиком функция сохраняется.

Разделы описания, которые мост переносит: справочники, документы, регистры
накопления, регистры сведений, перечисления, константы, отчёты, обработки,
подсистемы, виджеты, роли, регламентные задания, журналы и модули. У каждого
объекта записываются имя, тип, путь файла и заголовок; состав полей целевого
объекта идёт в табличную часть «Реквизиты», имена процедур модуля — туда же с
подписью параметров. Тип виджета (kpi, list, chart, actions) записывается в
описание объекта. Разделы описания `builtins` и `language` — контракт языка,
они в проектную базу не импортируются.

Функцию-владельца мост не назначает: закрепление объекта за узлом декомпозиции
— решение проектировщика. После импорта все объекты помечены контролем
«НеПроверено» и остаются без функции, правило аудита «Объект целевого проекта
без функции» находит незакреплённые, отчёт «Покрытие функций» показывает
долю закрытых. Проектировщик расставляет функции (`РасставитьФункции` с
параметром `Пары`), прогоняет аудит и помечает объекты проверенными.
