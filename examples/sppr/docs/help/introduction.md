# Что хранит проектная база

Проектная база описывает проектируемое решение как данные: дерево функций,
связи между функциями, объекты метаданных и файлы конфигурации, тестовые
сценарии, формальные правила проектирования, задачи и затраты времени.

Разделы:

* **Моделирование** — функции, связи, механизмы, подсистемы, роли;
* **Задачи** — задачи проектирования, комментарии, исполнители;
* **Ошибки** — ошибки, правила аудита и их публикации;
* **Планирование** — занятость и затраты времени.

База отделена от разрабатываемой конфигурации: она описывает решение, а
конфигурация — код. Связь между ними — регистр «Трассировка».
