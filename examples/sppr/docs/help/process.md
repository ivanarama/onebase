# Процесс

Процесс описывает последовательность шагов, которую каркас выполняет по
триггеру: внешнее событие, регламентное задание, запрос пользователя.
Каркас описывает процесс справочником «Процесс» с табличной частью «Шаги».

Поля процесса:

- **Код** и **Наименование** — опознавательные;
- **Триггер** — событие, которое запускает процесс;
- **Начало** и **Завершение** — состояния, из которых процесс стартует и
  которыми он заканчивается;
- **Функция** и **Исполнитель** — функция каркаса и роль, которая ведёт
  процесс целиком;
- **Проект** — проектная база, которой принадлежит процесс.

Шаг табличной части описывает одну операцию: номер, наименование, тип
(Шаг, Альтернатива, Вложенный), функцию каркаса, исполнителя и требуемый
результат. Функция шага связывает процесс с деревом функций: она обязана
быть утверждённой функцией каркаса.

Правило аудита «Процесс без функций» (код `AUD-PROC-NOFUNC`, важность
«Блокирующее») сторона «База»: процесс, в табличной части которого нет ни
одной строки, считается нарушением. Правило публикуется документом
«Публикация правила», применяется регламентным заданием «Аудит формальных
правил» и пишет результат в регистр «Результаты проверки». Отчёт
«Результаты аудита» показывает процесс без функций по коду правила.
