# Поиск владельца по контактам

```sh
onebase check --project examples/search-tableparts
onebase migrate --project examples/search-tableparts --sqlite /tmp/search-contacts.db
onebase run --project examples/search-tableparts --sqlite /tmp/search-contacts.db --port 8080
```

Создайте двух клиентов и заполните табличную часть «Контакты» телефонами и
Email. У первого добавьте одинаковый телефон в две строки. Найдите его по
части телефона в строке поиска списка: клиент и счётчик должны появиться
один раз. Тот же поиск работает в подборе ссылочного поля типа
`reference:Клиенты` в вашей конфигурации.

`search_fields` включает только наименование и явно указанный путь
`Контакты.Значение`. Если убрать ключ, телефоны ТЧ не участвуют в поиске.
`search_fields: []` даёт пустую выдачу для непустого запроса.

Поиск подстроки не требует FTS-переиндексации. Dotted path в `fulltext` пока
отклоняется проверкой. Перед запуском старого бинарника уберите путь ТЧ из
`search_fields`; данные остаются прежними.
