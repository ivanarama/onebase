# Регистрация звонка

Документ «Звонок» хранит сведения о разговоре: клиента, оператора, направление,
состояние, внешний номер абонента, длительность в минутах и описание.

1. Откройте список документов «Звонок» и нажмите «+ Создать».
2. Выберите клиента и оператора, укажите направление и состояние разговора.
3. Заполните номер абонента, длительность и описание по известным данным.
4. Нажмите «Записать» или используйте Ctrl+S.

Нумерация использует префикс `ЗВ-`, шесть цифр и годовой период.
Поле «ВнешнийId» хранит идентификатор канала Asterisk (`linkedid`).
Для ручной регистрации звонка подключение телефонии не требуется.

Кнопка «Справка» открывает эту статью. Полное руководство доступно в меню
«Система → Руководство пользователя».
