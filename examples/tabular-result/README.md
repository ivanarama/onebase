# Нативный ТабличныйДокумент

`onebase check --project examples/tabular-result`, затем обычные migrate/run на
своей синтетической базе. Открыть `/ui/report/TabularReport` и
`/ui/processor/TabularProcessor`.

Отчёт объявляет `result_proc` — функцию `.rep.os`, возвращающую ТабличныйДокумент.
Необязательный `query` выполняется с обычными RLS/масками; его строки доступны
функции в `Результат`, параметры — в `Параметры`. Без query функция строит документ
своим модулем. `ПолучитьМакет("Main")`/`Макеты.Получить("Main")` берёт макет из
`printforms/<имя отчёта>/Main.layout.yaml`. Можно загрузить несколько макетов:
имя файла без `.layout.yaml` является именем макета.

В управляемой форме: реквизит `type: SpreadsheetDocument, save: false`, элемент
`kind: ПолеТабличногоДокумента` с `data_path: Объект.<реквизит>`. Модуль присваивает
`Объект.Результат = ТабДок`. Это состояние просмотра, не поле сущности/не запись.
Для макетов обработки используется `Объект.ПолучитьМакет("Main")`; владелец
`document` в layout должен совпадать с именем обработки.

Viewer, «Печать», XLSX и PDF используют один серверный снимок без повторного
вызова модуля. Изменённые параметры не меняют старый снимок: период/филиал следует
печатать в шапке, как в исходном макете. Для пересчёта нажать «Сформировать».
Срок результата — 15 минут, он привязан к актору/сессии/правам/версии конфигурации.

Уровни `Вывести(Область, Уровень, Имя, Раскрыта)` формируют дерево. Сворачивание
локальное; печать/PDF содержат все строки, XLSX сохраняет outline и раскрытие.
Свойства: `ФиксацияСверху`, `ФиксацияСлева`, `ОтображатьСетку`,
`ОриентацияСтраницы`, `ИмяФайла`. Числовые форматы: ЧДЦ/ЧГ/ЧРД/ЧРГ/ЧН и
обычные Excel decimal/percent masks; числовой Value при этом остаётся числом.

Расшифровка: `Ячейка.Расшифровка = ТипизированнаяСсылка`. По умолчанию открывается
карточка через повторную проверку read/RLS. Допускаются также массивы/вложенные
массивы/структуры, строки, числа, даты, bool и пустые значения внутри коллекций.
Они доступны только объявленному обработчику поля; значения не передаются
браузером. Массивы/структуры копируются при публикации снимка. Callback получает
новую копию, каждую вложенную непустую ссылку сервер проверяет текущими read/RLS.
Менеджеры, функции, циклы и неподдержанные объекты отвергаются. Пределы:
глубина 32, 65536 узлов на документ, до 1 MiB на ячейку/8 MiB на документ
(счётчик памяти учитывает структуру и экранирование); усечения нет.
При объявленном у поля событии
`ОбработкаРасшифровки: МойОбработчик` оно получает серверную типизированную
переменную `Расшифровка` из снимка. Клиент передаёт только nonce/координаты;
чужой/просроченный результат и другой контекст формы отвергаются. Для бизнес-
действий обработчик запускает существующую прикладную команду с её проверками;
сам viewer ничего не записывает.

Оформление: `underline: true` ячейки layout, `Ячейка/Область.Подчеркивание`;
`borders: {bottom: hair}` и другие стороны. HTML/PDF hair = 0.25pt, XLSX =
нативный hair (style 7). Это отдельный вид от thin, не замена dotted.
