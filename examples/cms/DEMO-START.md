# Готовый пример: сайт и заказы

В релизном архиве рядом с программой находится `demo/cms-orders.db`:
конфигурация, девять товаров с картинками, покупатели и предыдущий заказ.
Установка PostgreSQL, сборка и выполнение команд не нужны.

1. Распакуйте архив релиза в доступную для записи папку. Откройте OneBase.
2. В лаунчере нажмите **Добавить**. Укажите название, выберите хранение
   конфигурации **В базе данных**, тип базы **Файловая (SQLite)** и файл
   `demo/cms-orders.db` из распакованного архива. Флажок создания пустой
   конфигурации оставьте выключенным. Нажмите **Добавить**.
3. Выберите базу и нажмите **Предприятие**. Войдите как `manager` с паролем
   `DemoOrders2026!`. Для конфигуратора: `admin` / `DemoLocal2026!`.
4. В блоке **Посмотреть сайт** на рабочем столе нажмите **Каталог**. Раздел
   **Каталог** позволяет выбрать товар и оформить заказ; у менеджера новый
   документ появится в разделе **Заказы и покупатели**.

Это общедоступные пароли вымышленного учебного примера. Используйте отдельную
копию базы для экспериментов. Все данные и иллюстрации включены в файл базы;
отправка почты, оплата и подключение служб доставки не настроены.

Исходники для разбора находятся в `examples/cms`. Для разработчика:
[инструкция для разработчика](https://github.com/ivanarama/onebase/tree/main/examples/cms).
