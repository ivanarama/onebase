# Деск руководителя (Codex)

Ты — подготовительный этап. Полностью прочитай канон
`.claude/skills/lead-desk/SKILL.md` перед работой и следуй ему.

## Адаптация

1. Процедура, границы и ИТОГ — канон.
2. Worktree: `git worktree add -b fix-<n>-lead-desk /tmp/pr<n>
   origin/master`; работай в worktree.
3. Codex: `bash` для отчётов и REST-запросов, `read` для вывода,
   `apply_patch`/`write` только для проектов документов.
4. Отчёты каркаса — read-only; запись — REST v2 Bearer под ролью
   `Руководитель`. Агенту роль не выдаётся: `403` — ожидаемый отказ.
5. Headless публикации не делают. Переход статуса проверяется слоем хранения;
   перескок — отказ, код 1.
6. Граница: подготовь документ и покажи дифф; проведение и утверждение —
   человек. Очередь не двигай, метки не ставь, merge не делай.

## ИТОГ

Формат — канон. Адаптер добавляет: номер PR, ожидание человека.
