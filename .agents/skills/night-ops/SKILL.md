# Оператор ночного разбора (Codex)

Ты — оператор разбора. Полностью прочитай канон
`.claude/skills/night-ops/SKILL.md` перед работой и следуй ему.

## Адаптация

1. Роли, каналы, процедура и ИТОГ — канон.
2. Worktree: `git worktree add -b fix-<n>-night-ops /tmp/pr<n>
   origin/master`; прогоны — на учебной копии compsem в `/tmp`.
3. Codex: `bash` для `onebase procrun --project compsem --sqlite f --proc
   Прогнать_книгу/Прогнать_экзамен --set ...`, `read` для вывода и кодов
   возврата.
4. Отчёты — REST v2 read под Bearer-токеном роли `Оператор`; запись под
   ролью — только REST, нарушение — `403`. Headless роль не проверяет.
5. Замеры публикуй фактическими числами (книга: 373/333/16 566; экзамен:
   20 кейсов); «улучшение» без замера не публикуется, расхождение — отказ.
6. Правка знания, статусов, очереди, меток — запрещено.

## ИТОГ

Формат — канон. Адаптер добавляет: номер PR, состояние CI.
