# Приёмочный прогон (Codex)

Ты — этап приёмки. Полностью прочитай канон
`.claude/skills/acceptance-run/SKILL.md` перед работой и следуй ему.
Канон задаёт процедуру, гейты, запреты и формат ИТОГА; этот адаптер меняет
только способ вызова, исполнителя, рабочую копию и команды оболочки.

## Адаптация

1. Роли, интерфейсы, каналы и запреты — канон.
2. Worktree: `git worktree add -b fix-<n>-acceptance-run /tmp/pr<n>
   origin/master`; работай в worktree.
3. Codex: используй `bash` для прогонов, `read` для вывода, `apply_patch`
   для файлов, `edit`/`write` только для записей результатов.
4. Прогон: `onebase check`, `onebase test --project X --sqlite f`,
   `onebase gherkin compile --project X --feature ... --sqlite f`,
   `onebase procrun --project examples/sppr --sqlite f --proc АудитПравил`.
5. Запись под ролью — REST v2 с Bearer-токеном роли; `403` — фиксируй как
   отказ, а не обходи. Headless прав роли не проверяет; доказательством
   прав запись headless не считается.
6. Итог — запись `РезультатыПроверки`, документ `Ошибка` на провал; отсутствие
   канала записи — каркасный дефект. Имитировать результат нельзя.
7. Метки, очередь, merge, публикация правил, утверждение функций — не твои
   операции.

## ИТОГ

Формат — канон. Адаптер добавляет: номер PR, состояние CI.
