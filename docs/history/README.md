# Архив рабочих заметок

Документы, которые описывают состояние проекта на конкретную дату и с тех пор не
поддерживаются. Они сохранены, потому что на них ссылаются планы в `Plans/` —
там это источник находки, а не руководство к действию.

**Ничего отсюда не является актуальным.** Где смотреть текущее состояние:

| Вопрос | Где ответ |
|---|---|
| Что уже умеет платформа | [`docs/features.md`](../features.md) |
| Что делается и что дальше | [`Plans/README.md`](../../Plans/README.md) |
| Что менялось между версиями | [`CHANGELOG.md`](../../CHANGELOG.md) |
| Как устроены объекты конфигурации | [`DEVELOPER.md`](../../DEVELOPER.md) |
