# Уровни и оформление групп отчёта

Статус: проект Draft, реализация/проверки ещё не завершены.
Зависимость source: ТабличныйДокумент #2627. Накопленный runtime начинается
с B30 d0cb9b15100ecdc6f13a8234dc4b2e3f99fa2eff. Общей установки документ не разрешает.

Для составного отчёта и HTML-просмотра ТабличногоДокумента слева над
переключателями групп отображаются кнопки `1 2 3…` по фактической глубине.
Кнопка N показывает уровни по N, закрывая более глубокие ветви;
последний уровень позволяет увидеть детализацию. Ручные переключатели
продолжают работать. Старых «Развернуть всё / Свернуть всё» нет.
У плоского результата без групп панель уровней отсутствует. Нажатие кнопок
не меняет серверный результат, печать, XLSX/PDF или сохранённый документ.

Во всех составных отчётах итог группы находится в самой строке группы.
Повторных строк-подвалов «··· Итого: … ···» нет, включая старый
`totals.subtotals: true`. Общее `totals.grand` сохраняет смысл, подпись
единственного общего итога — «Итого». Типы числовых ячеек XLSX сохраняются.
Заголовок колонки группировок использует доступное представление/label поля,
с fallback на имя при неопределённом происхождении/представлении.
Названия/порядок групп и вычисление ресурсов этим изменением не меняются.

Группы получают бледный фон: верхний уровень темнее, следующие светлее,
последний уровень/детали без дополнительного фона. HTML учитывает тёмную
тему и контраст. Фон также присутствует в Excel/PDF; плоские выгрузки его
не получают. Явное безопасное условное оформление ячеек сохраняется.
Кнопки уровней остаются только в HTML.

Проверка пачкой с универсальными отборами: публичная HTTP-страница с тремя
уровнями/деталями, цифры и ручные переключатели; плоский отчёт;
независимость выгрузки от свёртывания; отсутствие подвалов, единственный
общий итог, представления полей/XSS; светлая/тёмная темы; XML/styles/типы
ячеек XLSX и стили PDF. Браузер после Go END, собственная новая SQLite.
Shared :8448/:8444/:8443 без её слова не менять.

Меню делает platform2; зависимости параметров и обязательное скрытие ПДн
в представлениях ссылок делает platform3.
