# Скриншоты для README

Картинки, на которые ссылаются `README.md` и `README.en.md`. Имена файлов
фиксированы — README ждёт именно их.

Раньше английский README тянул скриншоты по ссылкам вида
`github.com/user-attachments/assets/…` — они живые, но привязаны к аккаунту и не
версионируются вместе с кодом. Файлы перенесены сюда, оба README теперь
ссылаются на репозиторий.

| `ai-assistant.png` | 1024×613 | ИИ-помощник разбирает остатки и маржу, расставляет приоритеты закупки |

| `report-result.png` | 1135×396 | Отчёт с группировками и итогами по иерархии «Организация → Номенклатура» |

Все файлы прогнаны через квантование до 256 цветов (`PIL … quantize(colors=256,
dither=NONE)`): для скриншотов интерфейса с плоскими заливками потерь на глаз
нет, а вес заметно ниже — семь кадров занимают 409 КБ. Добавляете новый кадр —
сделайте так же.

## Что можно улучшить

- **`report-result.png`** — узкая обрезка (1135×396) без окна вокруг. Рядом с
  полноразмерными кадрами выглядит вырезкой.
- **Конфигуратор** — дерево метаданных целиком нигде не показано, хотя README
  теперь рассказывает про режим «конфигурация в базе». Кандидат на
  `configurator.png`.

Кадры стареют вместе с интерфейсом: первый `form-designer.png` пришлось менять
через неделю — на нём был прежний сплит-вид и водяной знак «Активация Windows».
Меняешь заметно интерфейс — загляни сюда.

Ещё готовые кадры есть в статьях автора на Инфостарте — оттуда можно взять
недостающее, не переснимая:

- <https://infostart.ru/1c/articles/2756473/>
- <https://infostart.ru/1c/articles/2725452/>
- <https://infostart.ru/1c/articles/2707829/>

Добавляете новый файл — впишите его в таблицу выше и сошлитесь из README, иначе
он останется лежать мёртвым грузом в истории git.

## Требования к кадрам

- **Ширина 1200–1900 px**, PNG. Шире не нужно: GitHub ужимает по ширине колонки,
  а вес растёт.
- **Данные — из примеров или демо-базы**, а не из рабочей: реальные контрагенты,
  суммы и ФИО в публичном репозитории оставаться не должны. В кадре лаунчера
  проверьте, что пароли в строках подключения скрыты (`postgres://postgres:***@…`).
- **Окно без личного**: посторонние вкладки, панель задач, имя пользователя в
  путях — убрать. Нативное окно (`onebase-gui.exe`) снимать предпочтительнее
  браузера: нет адресной строки и панелей, кадр чище.
- **Светлая тема** — читается на обоих фонах GitHub.
- Вес в пределах ~300 КБ (`pngquant`/`oxipng` жмут без видимой потери). Это git,
  картинки останутся в истории навсегда.

## Социальная карточка

Превью для ссылок в мессенджерах и соцсетях задаётся не здесь, а в настройках
репозитория (Settings → General → Social preview), рекомендованный размер —
1280×640. Годится `dashboard.png`, обрезанный до этой пропорции. В git этот файл
класть не обязательно.
