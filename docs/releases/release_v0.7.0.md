OneBase **v0.7.0** — релиз про отчёты и интерфейс: появилась полноценная **компоновка отчётов (СКД)** с визуальным конструктором, **произвольные страницы** на DSL, выполнение **команд ОС** из модулей и **авторство конфигураций**.

Флагман — **СКД**: группировки, итоги, расшифровка в документ, вычисляемые показатели, условное оформление, экспорт в Excel и конструктор в конфигураторе с вкладками «Структура / Оформление / График».

## ✨ Новое

- **Компоновка отчётов (СКД)** — группировки и многоуровневая структура, итоги, условное оформление, декларативный график (ECharts). Сворачиваемые блоки (параметры / график / данные), «развернуть / свернуть всё», залипающий заголовок таблицы.
  - **Расшифровка** — drill-down детальной строки прямо в документ.
  - **Вычисляемые показатели** — выражения и проценты.
  - **Форматирование** — разрядность, знаки, проценты, выравнивание значений.
  - **Экспорт в Excel** с группами и итогами.
  - **Конструктор в конфигураторе** — вкладки «Структура», «Оформление», «График» + кнопка предпросмотра; round-trip блока `composition` при сохранении.
- **Страницы** — произвольные представления на DSL: структурные блоки (список, таблица, график, HTML), кнопки-действия (вызов процедуры-обработчика), открываются из меню, ссылки на объекты базы. CRUD объекта «страница» в конфигураторе, i18n подписей блоков.
- **ВыполнитьКоманду** — выполнение команд ОС из DSL за флагом `AllowExec` (выключен по умолчанию, без shell, таймаут, аудит).
- **Авторство конфигураций** — поля `author` / `copyright` / `license` в `app.yaml`, редактирование в конфигураторе, экран «О программе» показывает авторство конфигурации и платформы.
- **Каталог возможностей** — `docs/features.md` как источник раздела «На тестировании» на сайте.

## 🔧 Изменения и исправления

- `feat(dsl)`: `НСтр` по умолчанию берёт язык интерфейса пользователя; несколько переменных в одном `Перем` через запятую
- `feat(launcher)`: путь к файлу SQLite в списке баз
- `feat(configurator)`: кликабельные ошибки в модуле, регистронезависимая подсветка DSL, шаблоны конструкций; прокрутка вкладок Бэкапы / Файлы / Импорт; создание общего модуля из дерева
- `refactor(report)`: единый обход дерева СКД для HTML и Excel, общий `EChartsOption` — кросс-СУБД совместимость виджетов
- `fix(security)`: определение типа картинки по содержимому, обезвреживание SVG, санитайзер raw-HTML страниц через bluemonday
- `fix(report)`: ключ группировки, сортировка nil, round-trip `composition`, сохранение `titles` и `detail_link`; пустая ячейка вместо 0 для неопределённого показателя
- `fix(ui)`: декодирование имени страницы в `/ui/page/{name}`, форма `СсылкаНаОбъект`, экранирование `style` и «/»
- `fix(configurator)`: создание общего модуля из дерева (#95), прокрутка вкладок (#94), правки DSL-редактора (#102–105)

## ⚠️ Breaking changes

Нет. `ВыполнитьКоманду` по умолчанию выключен — существующие конфигурации работают без изменений.

## 📦 Установка

### Windows
1. Скачайте `onebase-windows-amd64.zip`
2. Распакуйте в любую папку (например `C:\onebase\`)
3. Двойной клик на **`onebase-gui.exe`** — откроется лаунчер в браузере

### Linux
```bash
tar xzf onebase-linux-amd64.tar.gz
./onebase-linux-amd64/onebase start
```

### macOS
```bash
tar xzf onebase-darwin-amd64.tar.gz
./onebase-darwin-amd64/onebase start
```

### Требования
- PostgreSQL 14+ или SQLite (по умолчанию, без установки)
- Современный браузер (Chrome, Edge, Firefox)
