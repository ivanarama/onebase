## Что нового

`v0.8.1` собирает изменения после `v0.8.0`: пользовательские варианты отчётов, экспорт отчётов в PDF, новый `onebase lint`, историю версий конфигурации, автобэкапы, свёртку базы, realtime-уведомления, CTI-демо, улучшения конфигуратора и серию исправлений UI/DSL.

## Главное
<img width="1396" height="963" alt="НастройкиСКД" src="https://github.com/user-attachments/assets/17bddb25-c1a9-4926-884a-ab478b280414" />
- **Варианты отчётов для пользователя** — в пользовательском режиме настройки отчёта можно сохранить именованным вариантом и потом выбрать из списка. Настройки по умолчанию заполняются текущей компоновкой отчёта, а сохранённые варианты нормализуются, чтобы пустые override-настройки не затирали группировки и ресурсы.
- **Стабильнее формирование отчётов** — исправлены пустые флаги группировок и показателей, сброс при сохранении варианта, автогенерация имени нового варианта, применение сохранённых настроек и регрессия проверки формата отчёта.
- **PDF-выгрузка отчётов** — из пользовательского интерфейса можно выгружать отчёт в PDF.
- **`onebase lint`** — добавлен отдельный режим статической проверки конфигураций, включая проверки DSL, scope hygiene и форматов отчётов.
- **Эксплуатация и данные** — появились снимки версий конфигурации, UI истории конфигурации, запись версии при deploy, автобэкап по расписанию и свёртка базы.
- **Realtime и CTI** — добавлена внутренняя шина уведомлений, SSE `/ui/events`, DSL-функция `ОтправитьУведомление` / `PublishNotification` и эталонное callcenter/telephony demo.

## Изменения

### Отчёты

- Добавлено хранение именованных пользовательских вариантов отчётов.
- Добавлены выбор и сохранение вариантов прямо со страницы отчёта.
- Исправлено заполнение настроек по умолчанию: текущие группировки и ресурсы больше не открываются пустыми.
- Исправлено сохранение вариантов с пустыми или частичными override-настройками.
- Исправлена повторная подстановка флагов группировок и ресурсов независимо от регистра имён.
- Исправлен сценарий, когда `Применить` работал, а `Сохранить вариант` сбрасывал сформированный отчёт и настройки.
- Добавлено автоматическое имя для нового варианта, если пользователь не ввёл название.
- Исправлена регрессия проверки `excel_html` и диагностика undefined DSL calls/no-op.
- Добавлена PDF-выгрузка отчётов.
- Нормализован числовой формат вывода в отчётах, чтобы значения не раскрывались лишними знаками после запятой.

### Конфигуратор и пользовательский UI

- Добавлен настраиваемый вид плитки списка.
- Доработан визуальный конструктор форм и выбор вида конструктора.
- Исправлено поведение вкладок приложения.
- Выбор реквизитов списка теперь применяется во всех режимах.
- Сохраняется раскрытие дерева при скрытом `Наименование`.
- Авто-сумма табличной части включается только при явном `auto_sum`.
- Убрано дублирование `Главная` в панели подсистем.
- Добавлено явное предупреждение, когда формат `ПолеДаты` не применяется.
- Добавлена активность справочников и исправлен переключатель активности в trade demo.
- Добавлены guardrail-проверки удаления managed forms и объектов свёртки.
- Запрещены HTTP-сервисы с пустым runtime secret.

### Проверки, DSL и инструменты разработчика

- Добавлен `onebase lint`.
- Добавлен детектор чтения из чужой области видимости.
- Исправлена изоляция областей видимости функций для коллекций.
- Undefined DSL calls теперь корректно проваливают проверку.
- Секреты вида `${env:...}` больше не требуют значения при линте.
- Расширены AI developer tools: `describe`, `explain`, `query`, `impact`, `refactor`, `schema`, `eval`, `examples`, `mcp`.
- Добавлен MCP-сервер и документация по MCP.
- Диагностика переведена на `slog`.
- На экране «О программе» и в шапке конфигуратора теперь показываются дата и SHA сборки.

### Данные, бэкапы и эксплуатация

- Добавлены снимки версий конфигурации и UI истории конфигурации.
- `deploy` записывает релизную версию конфигурации.
- Исправлена сортировка версий конфигурации по разобранному времени.
- Добавлен автобэкап по расписанию.
- Добавлена свёртка базы: регистры накопления, бухгалтерский регистр через вспомогательный счёт, опциональная обрезка инфорегистров.
- Добавлен жёсткий гейт по повисшим ссылкам при свёртке.
- Доработан graceful shutdown scheduler и тестовое покрытие вокруг него.
- Demo deploy сохраняет доступ к AI-данным.

### Realtime, уведомления и телефония

- Добавлена внутрипроцессная шина уведомлений.
- Добавлен SSE endpoint `/ui/events` и JS-мост для браузера.
- Добавлена DSL-функция `ОтправитьУведомление` / `PublishNotification`.
- Добавлено demo callcenter: справочники, документы, статусы операторов, страница телефонии, тест входящего звонка.
- Добавлен click-to-call через Asterisk ARI originate, screen-pop, журнал звонков, KPI и панель оператора.
- Добавлена глобальная всплывающая карточка входящего звонка.

### Примеры и документация

- Пример `trade` приведён к чистому `onebase lint`.
- Обновлён каталог возможностей и публичный roadmap.
- Добавлены и обновлены планы по realtime, CTI, AI tools, свёртке базы, multi-user readiness и изоляции scope.
- Добавлен `DEVELOPER.md`.
- Обновлены i18n-переводы для истории конфигураций и связанных UI-сообщений.

## Совместимость

- Ручная миграция не требуется: новые системные таблицы и настройки создаются приложением при использовании соответствующих функций.
- `onebase check` / `onebase lint` стали строже: конфигурации с несуществующими DSL-вызовами, некорректными форматами отчётов или пустыми runtime secrets теперь падают раньше.
- Формат установки и имена релизных артефактов не изменились.

## Установка

### Windows

1. Скачайте `onebase-windows-amd64.zip`.
2. Распакуйте в любую папку, например `C:\onebase\`.
3. Запустите `onebase-gui.exe` или выполните `onebase start` из терминала.

### Linux

```bash
tar xzf onebase-linux-amd64.tar.gz
sudo mv onebase-linux-amd64/onebase /usr/local/bin/
onebase start
```

### macOS

```bash
tar xzf onebase-darwin-amd64.tar.gz
sudo mv onebase-darwin-amd64/onebase /usr/local/bin/
onebase start
```

### Требования

- PostgreSQL 14+ для серверного режима.
- Современный браузер: Chrome, Edge или Firefox.
