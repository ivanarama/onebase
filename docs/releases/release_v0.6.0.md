OneBase **v0.6.0** — самый крупный релиз платформы с момента v0.5.0 (87 коммитов).

Главное событие — встроенный **ИИ-помощник** на базе LLM: он работает и в пользовательском режиме, и в конфигураторе, сам запрашивает данные базы (tool-use) и видит метаданные конфигурации. Плюс долгожданное **субконто** в регистре бухгалтерии, **мобильный доступ с PWA** и перевод табличных частей на **SlickGrid**.

## ✨ Новое

- **ИИ-помощник (LLM)** — чат-ассистент в рабочем UI и помощник разработчика в конфигураторе. Провайдеры Anthropic / OpenAI / Gemini, tool-use (ИИ сам запрашивает данные и метаданные базы), vision, builtin `ЗапросИИ` для DSL. Конфигурация провайдера и API-ключей — в `app.yaml` с подстановкой из переменных окружения. Гибкий контроль доступа к данным для не-админов.
- **Субконто (аналитика)** в регистре бухгалтерии — детализация проводок по разрезам учёта (до 5 уровней).
- **Мобильный доступ и PWA** — адаптивная вёрстка, service worker с авто-версией кэша, manifest. Платформу можно «установить» как приложение на телефон.
- **SlickGrid для табличных частей** — виртуализированный грид по умолчанию: большие ТЧ, сортировка, итоги, выделение в стиле 1С, чекбоксы для `bool`, подсветка отрицательных значений.
- **Команды табличных частей и диалог подбора** — обобщённый механизм операций над строками ТЧ с мультивыбором.
- **Пометка на удаление ↔ проведение** — инвариант «нельзя провести помеченный», авто-отмена проведения при пометке, DSL-методы `ПометитьНаУдаление` / `СнятьПометку` / `ОтменитьПроведение`.
- **Вкладки в редакторе объектов конфигуратора** — Данные/Формы/Печатные/Модули у справочников и документов, Параметры/Запрос/Диаграмма у отчётов; `Ctrl+S` сохраняет активную вкладку.
- **Импорт конфигурации 1С** — загрузка XML-выгрузки в конфигуратор.

## 🔧 Изменения и исправления

- `feat(dsl)`: чтение табличной части документа по ссылке — `Док.ТЧ`
- `feat(query)`: кросс-СУБД совместимость виджетов (SQLite + PostgreSQL)
- `feat(ui)`: звёздочка несохранённых изменений + предупреждение при закрытии формы
- `fix(query)`: трансляция скалярных 1С-функций `ОКР` / `АБС` / `ЦЕЛ` в SQL
- `fix(account)`: бухгалтерия в `procrun` / `migrate`, id движений, `МоментВремени` в виртуальных таблицах
- `fix(storage)`: implicit `uuid→text` cast для PostgreSQL без рекурсии; FK drop через `pg_class`
- `fix(backup)`: совместимость импорта `.obz` SQLite→PostgreSQL, JSONB double-encoding, CP1251-транскодирование
- `fix(llm)`: маскирование API-ключей в админ-форме, редакция секретов в ошибках, потолок тела ответа
- множество правок UX SlickGrid и стабильности гридов

## 📦 Установка

### Windows
1. Скачайте `onebase-windows-amd64.zip`
2. Распакуйте в любую папку (например `C:\onebase\`)
3. Двойной клик на **`onebase-gui.exe`** — откроется лаунчер в браузере

### Linux
```bash
tar xzf onebase-linux-amd64.tar.gz
./onebase-linux-amd64/onebase start
```

### macOS
```bash
tar xzf onebase-darwin-amd64.tar.gz
./onebase-darwin-amd64/onebase start
```

### Требования
- PostgreSQL 14+ или SQLite (по умолчанию, без установки)
- Современный браузер (Chrome, Edge, Firefox)
