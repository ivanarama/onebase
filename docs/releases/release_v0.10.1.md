## 🎯 Главное

![Граф этапов без обрезанных связей](https://github.com/ivanarama/onebase/releases/download/v0.10.1/onebase-v0.10.1-stages-workflow.png)

`v0.10.1` — патч-релиз после `v0.10.0`: исправлены найденные живой
эксплуатацией расхождения форм между SQLite и PostgreSQL, ошибки запуска и
обновления, а также крайние случаи примера «Сайт». Отдельно укреплён жизненный
цикл приложения: фоновые исполнители и HTTP-сервер теперь запускаются и
останавливаются в одном предсказуемом порядке.

## 🧾 Формы и таблицы

- **Дата в табличной части** получила календарный редактор и единый формат
  показа. Дата `14.03.1985` больше не превращается на SQLite в предыдущий день,
  а неверный текст отклоняется одинаково на обеих СУБД
  ([#1079](https://github.com/ivanarama/onebase/pull/1079),
  [#1081](https://github.com/ivanarama/onebase/pull/1081)).
- **Типовое отображение значений** теперь едино для списков, деревьев, отчётов,
  панели деталей и виртуальных колонок: флажки показываются как `✓`/`—`, даты —
  в местной зоне, перечисления — подписью, ссылки — представлением, richtext —
  текстом без HTML-тегов
  ([#1075](https://github.com/ivanarama/onebase/pull/1075),
  [#1082](https://github.com/ivanarama/onebase/pull/1082),
  [#1084](https://github.com/ivanarama/onebase/pull/1084)).
- Ошибка даты или числа в шапке формы возвращает заполненную форму с понятным
  сообщением, а не отдельную страницу ошибки. Изображение в панели деталей
  вписывается в доступную ширину и высоту
  ([#1087](https://github.com/ivanarama/onebase/pull/1087)).
- Дуги переходов в отчёте по этапам больше не выходят за границы диаграммы на
  широком экране ([#1061](https://github.com/ivanarama/onebase/pull/1061)).

## 🚀 Запуск и обновление

- Ошибка запуска базы показывается в копируемом диалоге без шума от справки
  CLI. Для неполной миграции лаунчер предлагает безопасно дозаполнить коды;
  `onebase renumber` пропускает ещё не созданные таблицы
  ([#1068](https://github.com/ivanarama/onebase/pull/1068),
  [#1087](https://github.com/ivanarama/onebase/pull/1087)).
- Экран самообновления различает нехватку прав, небезопасное расположение
  бинаря и отсутствие подходящего релиза, поэтому больше не советует запуск от
  администратора там, где он не поможет
  ([#1069](https://github.com/ivanarama/onebase/pull/1069)).
- Запуск UI и API сведён к общему жизненному циклу `Build / Run / Close`:
  очередь, планировщик, watcher и HTTP-сервер корректно дренируются при
  остановке ([#1088](https://github.com/ivanarama/onebase/pull/1088)).

## 🌐 Пример «Сайт»

- Незаполненная картинка больше не попадает в `src` и `og:image` как `%3Cnil%3E`
  ([#1064](https://github.com/ivanarama/onebase/pull/1064)).
- YML-импорт строит устойчивые адреса без дублей и корректно транслитерирует
  мягкий и твёрдый знаки; витрина использует внешнюю картинку выгрузки, пока
  локальная медиатека не заполнена
  ([#1073](https://github.com/ivanarama/onebase/pull/1073)).
- Корень полностью пустого сайта отвечает `200` со страницей-подсказкой вместо
  `404`. Ссылки из рабочего стола на публичный сайт можно открывать в новой
  вкладке через `new_tab: true`; отказ прав при заполнении демо-контента теперь
  называет требуемую роль и сохраняет исходную ошибку
  ([#1086](https://github.com/ivanarama/onebase/pull/1086)).

## 🛡️ Надёжность разработки

- Windows-тесты стали обязательным гейтом PR, а проверки остановки scheduler и
  UI больше не мигают из-за преждевременного закрытия базы
  ([#1063](https://github.com/ivanarama/onebase/pull/1063),
  [#1087](https://github.com/ivanarama/onebase/pull/1087)).
- Остаточный lifetime-lock SQLite `*.onebase.lock` после жёсткой остановки
  сервера больше не загрязняет `git status`
  ([#1070](https://github.com/ivanarama/onebase/pull/1070)).

## ⚠️ Изменения поведения

- Пустая дата или число в строке табличной части теперь записывается как `NULL`,
  а не как пустая строка. Прикладной код, сравнивавший такое поле с `""`, нужно
  перевести на проверку незаполненности.
- Дата `14.03.1985` принимается наравне с `1985-03-14`. Уже сохранённые в SQLite
  произвольные строки в колонках даты автоматически не преобразуются.
- Отображение `bool` меняется с внутренних `1`/`0` или `true`/`false` на
  `✓`/`—`. Сохранённые данные и REST-формат при этом не меняются.
- `new_tab` — опциональный признак; существующие actions-виджеты без него
  продолжают открывать ссылку в текущей вкладке.

## 📦 Установка

### Windows

1. Скачайте `onebase-windows-amd64.zip` (на Windows ARM —
   `onebase-windows-arm64.zip`)
2. Распакуйте в любую папку, например `C:\onebase\`
3. На amd64 запустите `onebase-gui.exe`

В arm64-архиве `onebase-gui.exe` нет: запустите `onebase.exe start`, лаунчер
откроется в браузере.

### Linux

```bash
tar xzf onebase-linux-amd64.tar.gz
./onebase-linux-amd64/onebase start
```

Для Raspberry Pi, ARM-мини-ПК и NAS используйте
`onebase-linux-arm64.tar.gz`.

### macOS

```bash
tar xzf onebase-darwin-arm64.tar.gz
./onebase-darwin-arm64/onebase start
```

Для Intel Mac используйте `onebase-darwin-amd64.tar.gz`.

При обновлении установленной копии замените бинарь в `PATH`, затем проверьте:

```bash
onebase version
```

### Требования

- PostgreSQL 14+ нужен только для многопользовательского режима
- Для SQLite-режима дополнительных зависимостей нет
