OneBase v0.8.0 — большой релиз после v0.7.0: визуальный конструктор управляемых форм, торговое оборудование с агентом и фискальным регистратором, вкладочный интерфейс, дерево файлов конфигурации, многоязычный конфигуратор и серьёзное security hardening.

Фокус релиза — сделать разработку и эксплуатацию конфигураций ближе к полноценной low-code/1С-подобной среде: формы теперь можно собирать мышью, интерфейс работает во вкладках, конфигуратор безопаснее и удобнее, а оборудование кассира подключается через локальный агент.

## ✨ Новое

- **Визуальный конструктор управляемых форм** — round-trip YAML через `yaml.Node`, интерактивный холст, палитры реквизитов/структуры/табличных частей, панель свойств, drag/drop, операции set/insert/move/delete.
- **Доводка конструктора форм** — события элементов и формы, создание обработчиков `.form.os`, свойства формы, видимость штатных действий, переключатель radio/select, наборы значений, табличные части с выбором колонок, предпросмотр.
- **Управляемые формы в рантайме** — `ПолеДаты`, вложения, серверный хук `ПриЧтенииНаСервере`, серверные события формы, списки значений, скрытие штатной кнопки удаления через `actions.delete.visible`.
- **Вкладочный интерфейс** — глобальный и персональный режим открытия форм, вкладки рантайма, защита от потери несохранённых правок, дубликат/управление вкладками.
- **Дерево файлов конфигурации** — просмотр файлов конфигурации и открытие в редакторе из конфигуратора.
- **Торговое оборудование** — фискальный регистратор ККТ через АТОЛ, локальный device agent, браузерный мост к агенту, дисплей покупателя, сканеры/весы/эквайринг, DSL `ПодключитьОборудование`.
- **Экспорт в 1С:БП** — внешняя обработка `.obform`, контракт обмена, экспорт табличных частей по UID, DSL-поиск документа по UUID.
- **AI и LLM** — UI настроек провайдеров/моделей/задач, tool-use для OpenAI и Gemini, права доступа к данным, аудит AI-действий.
- **Многоязычность конфигуратора** — переводы синонимов объектов/реквизитов/регистров/отчётов/обработок/констант/подсистем, переводы значений перечислений, единый режим переводов.
- **Навигация и иконки** — Lucide-иконки разделов навигации и нормализация имён иконок.
- **Отчёты после v0.7.0** — runtime-настройки отчётов, варианты компоновки, кросс-таблицы, отборы, Excel с учётом настроек, оформление вывода: линии сетки и зебра.
- **Load testing** — документация HTTP-нагрузочного тестирования.

## 🔧 Изменения

- **Безопасность**: html/template и go:embed в конфигураторе, контекстное экранирование, raw-view symlink protection, XSS-защиты ref-picker/вложений/страниц, CSS whitelist для raw HTML, `nosniff`, postMessage hardening, fail-closed RLS на чтение.
- **Хранилище и данные**: GC blob-ов, защита legacy blob paths, точный `COUNT` для MatchCatalogByField, хранение пользовательских настроек отчётов и режима открытия форм.
- **DSL**: тело модуля обработки, раздел `Перем`, safe-match по реквизиту, понятные ошибки parser/member access, ключевые слова как имена свойств после точки, встроенные функции оборудования.
- **Конфигуратор**: разбиение html/template, static CSS/JS, валидная вставка реквизита в YAML формы, создание объекта с правильным фокусом в дереве, ресайз боковых панелей, сохранение табличных частей и точности чисел.
- **UI**: скрытие админ-пунктов от неадминистраторов, безопасный ref-picker, полировка tabs/form mode, управляемые формы CRM в `forms/<entity>/`.
- **i18n**: немецкие umlauts/semantic terms, переводы дерева файлов и вкладок на локали.
- **Оборудование**: идемпотентность, сверка чеков, округление денег, анти-SSRF и token hardening device agent.
- **Документация**: обновлён `docs/features.md`, добавлен `docs/release-template.md`.

## ⚠️ Breaking changes

Нет известных breaking changes для существующих конфигураций. Новые возможности включаются конфигурацией или настройками, а опасные операции, включая выполнение команд ОС, оборудование и AI-доступы, защищены флагами и правами.

## 📦 Установка

### Windows
1. Скачайте `onebase-windows-amd64.zip`
2. Распакуйте в любую папку, например `C:\onebase\`
3. Запустите `onebase-gui.exe` или `onebase start`

### Linux
```bash
tar xzf onebase-linux-amd64.tar.gz
./onebase-linux-amd64/onebase start
```

### macOS
```bash
tar xzf onebase-darwin-amd64.tar.gz
./onebase-darwin-amd64/onebase start
```

### Требования
- PostgreSQL 14+ или SQLite по умолчанию, без установки
- Современный браузер: Chrome, Edge или Firefox
