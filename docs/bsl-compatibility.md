## Матрица переноса BSL и обращений к БСП

Проверенные сигнатуры OneBase через eval; версии 1С и БСП не сертифицированы. Контекст UI, права и полный API менеджеров требуют отдельной проверки.

Источник — встроенный реестр проверенных контрактов плана 179, срез 2. Обновление документа: `onebase migrate-matrix > docs/bsl-compatibility.md`. JSON: `onebase migrate-matrix --json`. Частоты конкретной выгрузки: `onebase migrate-matrix /path/to/export` (те же правила и кодировки, что у `migrate-scan`).

Вердикты: **поддерживается без изменений** — только указанная сигнатура; **механически** — указанное ручное переписывание с проверенным результатом; **нативный аналог** — реализованный и проверенный целевой контракт; **пробел платформы** — ограничение со ссылкой на заявку; **не поддерживается** — указанный исходный контракт не переносится. Команда не преобразует исходники. Наличие механизма или плана не доказывает эквивалентность API БСП.

Примеры запускаются через `onebase eval --project examples/trade --snippet --json '<код>'`. Для помеченного SQLite-примера добавьте `--sqlite /tmp/compatibility.db`; это проверка фабрики запроса, без изменения бизнес-данных. Ошибка в отрицательном примере — ожидаемое ограничение, а не успешный перенос. Матрица не меняет диагностик W040 или результата `migrate-scan`.

Выгрузка не задана: частоты **не измерены**, «—» не означает ноль. Исторические числа из плана сюда не переносятся.

| ID / конструкция | Сигнатура | Вердикт | Перенос и границы | Частота / файлов |
|---|---|---|---|---|
| structure — Структура | `Новый Структура(Имена, Значения...)` | поддерживается без изменений | Строка имён и значения; не обещает копирование структуры или выходной параметр Свойство.  | — |
| structure-output — Выходной параметр Свойство | `С.Свойство(Ключ, Выход)` | пробел платформы | Одноаргументный Свойство возвращает значение, не Булево. Выходной параметр отвергается; срез 5. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| array — Пустой массив | `Новый Массив()` | поддерживается без изменений | Заполнение через Добавить, чтение по индексу; размерности не поддержаны.  | — |
| array-sized — Одномерный массив из двух пустых элементов | `Новый Массив(2)` | механически | Аргумент размера игнорируется. Для этого фиксированного размера: пустой массив и два Добавить(Неопределено). Многомерность, общий вычисляемый размер и автоматическая конверсия не заявлены.  | — |
| map — Соответствие | `Новый Соответствие(); Вставить(Ключ, Значение)` | поддерживается без изменений | Пустой конструктор и операции коллекции; аргументы конструктора не переносятся.  | — |
| value-table — Таблица значений: свёртка и итог | `Новый ТаблицаЗначений(); Колонки.Добавить(Имя); Свернуть; Итог` | поддерживается без изменений | Колонки без типов, две строки одной группы. Это ValueTable, не массив структур.  | — |
| value-table-column — Объект типизированной колонки | `Т.Колонки.Получить(0)` | пробел платформы | Возвращается имя колонки строкой; типы колонок не обеспечиваются. Срез 5. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| value-table-copy — Копирование таблицы | `Т.Скопировать()` | пробел платформы | Метод не реализован: вызов молча возвращает Неопределено, а не копию таблицы. Срез 5. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| nstr — Явный язык локализации | `НСтр(СтрокаЛокализации, Язык)` | поддерживается без изменений | Обычные сегменты без точки с запятой внутри перевода.  | — |
| nstr-fallback — Отсутствующий язык | `НСтр(СтрокаЛокализации, ОтсутствующийЯзык)` | пробел платформы | OneBase выбирает первый непустой сегмент; эквивалентность исходному поведению проверяется отдельно, срез 4. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| nstr-semicolon — Разделитель внутри перевода | `НСтр("en='Part; continuation'", "en")` | пробел платформы | Текст обрезается по точке с запятой, даже внутри кавычек; срез 4. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| template — Строковые параметры шаблона | `СтрШаблон(Шаблон, Строка1, Строка2)` | поддерживается без изменений | Проверенный случай %1/%2 без маркеров подстановки внутри аргументов. Числа, даты, %10 и нехватка аргументов этим контрактом не покрыты.  | — |
| template-recursion — Маркер подстановки внутри аргумента | `СтрШаблон("%1 / %2", "A", "%1")` | пробел платформы | Повторная подстановка даёт A / A; исходное поведение требует сравнительной фикстуры, срез 4. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| raise — Вызвать исключение | `ВызватьИсключение "описание"` | поддерживается без изменений | Оператор без скобок сохраняется. Не переписывать на несуществующий ВыброситьИсключение.  | — |
| message — Сообщение из CLI eval | `Сообщить(Текст)` | поддерживается без изменений | eval возвращает сообщение в messages. Статус и адресное выделение поля не покрыты; доставка в UI — отдельный контракт.  | — |
| value-storage — Хранилище значения | `Новый ХранилищеЗначения(Значение)` | не поддерживается | Конструктор в DSL отсутствует. Сериализацию и права хранения нужно проектировать отдельно. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| notification — Описание оповещения | `Новый ОписаниеОповещения(Имя, Объект)` | не поддерживается | Тип клиентского callback не реализован. Диалоги OneBase имеют собственный событийный контракт. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| temporary-address — Проверка адреса временного хранилища | `ЭтоАдресВременногоХранилища(Адрес)` | не поддерживается | Функция и модель адресов временного хранилища 1С не реализованы в eval. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| temporary-read — Чтение временного хранилища | `ПолучитьИзВременногоХранилища(Адрес)` | не поддерживается | Адрес 1С не является файлом или вложением OneBase; автоматической замены нет. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| bsp-template — Подстановка БСП через общий модуль | `СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(...)` | пробел платформы | Модуль БСП не поставляется. СтрШаблон уже работает в ограниченной сигнатуре template; эквивалентность полной сигнатуре метода БСП не проверена. Срез 3. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| bsp-value — Реквизит объекта через БСП | `ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Ссылка, Имя)` | пробел платформы | БСП не поставляется; доступ к данным требует отдельного контракта прав и контекста. Срез 3. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| query — Запрос в контексте БД | `Новый Запрос(); Текст; Выполнить().Выгрузить()` | поддерживается без изменений | Фабрика запроса требует подключённой БД. Пример проверяет литеральный SELECT на SQLite, не API всех виртуальных таблиц, записи или права UI.  | — |
| query-constructor-text — Текст в конструкторе запроса | `Новый Запрос(Текст)` | механически | Аргументы конструктора игнорируются: Текст остаётся пустым. Перенести текст в отдельное присваивание З.Текст, как в query. Автоматический конвертер не добавлен.  | — |
| bsp-language — Код языка через общий модуль БСП | `ОбщегоНазначения.КодОсновногоЯзыка()` | пробел платформы | Общий модуль БСП не поставляется. НСтр не заменяет этот API; срез 3. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| bsp-module — Общий модуль через БСП | `ОбщегоНазначения.ОбщийМодуль(Имя)` | пробел платформы | Общий модуль БСП и его API рефлексии не поставляются; срез 3. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |
| bsp-subsystem — Проверка подсистемы через БСП | `ОбщегоНазначения.ПодсистемаСуществует(Имя)` | пробел платформы | Наличие YAML-подсистем не реализует API общего модуля БСП; срез 3. [#1479](https://github.com/ivanarama/onebase/issues/1479), план 179 | — |

### Исполняемые примеры

#### structure

```bsl
С = Новый Структура("А,Имя", 7, "Ada"); Возврат С.А;
```

Результат JSON: `"7"`.

#### structure-output

```bsl
С = Новый Структура("А", 7); Выход = Неопределено; Возврат С.Свойство("А", Выход);
```

Ожидается ошибка исполнения: `выходной параметр не поддерживается`.

#### array

```bsl
А = Новый Массив(); А.Добавить(7); Возврат А[0];
```

Результат JSON: `"7"`.

#### array-sized

```bsl
А = Новый Массив(2); Возврат А.Количество();
```

Результат JSON: `0`.

```bsl
А = Новый Массив(); А.Добавить(Неопределено); А.Добавить(Неопределено); Возврат А;
```

Результат JSON: `[
          null,
          null
        ]`.

#### map

```bsl
М = Новый Соответствие(); М.Вставить("А", 9); Возврат М.Получить("А");
```

Результат JSON: `"9"`.

#### value-table

```bsl
Т = Новый ТаблицаЗначений(); Т.Колонки.Добавить("Группа"); Т.Колонки.Добавить("Сумма"); Р = Т.Добавить(); Р.Группа = "А"; Р.Сумма = 100; Р = Т.Добавить(); Р.Группа = "А"; Р.Сумма = 250; Т.Свернуть("Группа", "Сумма"); Рез = Новый Массив(); Рез.Добавить(Т.Количество()); Рез.Добавить(Т.Итог("Сумма")); Возврат Рез;
```

Результат JSON: `[
          1,
          350
        ]`.

#### value-table-column

```bsl
Т = Новый ТаблицаЗначений(); Т.Колонки.Добавить("Сумма"); Возврат Т.Колонки.Получить(0);
```

Результат JSON: `"Сумма"`.

#### value-table-copy

```bsl
Т = Новый ТаблицаЗначений(); Т.Колонки.Добавить("Число"); Р = Т.Добавить(); Р.Число = 7; Возврат Т.Скопировать();
```

Результат JSON: `null`.

#### nstr

```bsl
Возврат НСтр("ru='Привет'; en='Hello'", "en");
```

Результат JSON: `"Hello"`.

#### nstr-fallback

```bsl
Возврат НСтр("ru='Привет'; en='Hello'", "de");
```

Результат JSON: `"Привет"`.

#### nstr-semicolon

```bsl
Возврат НСтр("ru='Часть; продолжение'; en='Part; continuation'", "en");
```

Результат JSON: `"Part"`.

#### template

```bsl
Возврат СтрШаблон("Hello, %1 / %2!", "Ada", "Bob");
```

Результат JSON: `"Hello, Ada / Bob!"`.

#### template-recursion

```bsl
Возврат СтрШаблон("%1 / %2", "A", "%1");
```

Результат JSON: `"A / A"`.

#### raise

```bsl
Попытка ВызватьИсключение "пример"; Исключение Возврат Истина; КонецПопытки; Возврат Ложь;
```

Результат JSON: `true`.

#### message

```bsl
Сообщить("пример"); Возврат 1;
```

Результат JSON: `"1"`. Сообщения: `["пример"]`.

#### value-storage

```bsl
Х = Новый ХранилищеЗначения(1); Возврат Х;
```

Ожидается ошибка исполнения: `неизвестный тип ХранилищеЗначения`.

#### notification

```bsl
Возврат Новый ОписаниеОповещения("Ответ", Неопределено);
```

Ожидается ошибка исполнения: `неизвестный тип ОписаниеОповещения`.

#### temporary-address

```bsl
Возврат ЭтоАдресВременногоХранилища("x");
```

Ожидается ошибка исполнения: `unknown function "ЭтоАдресВременногоХранилища"`.

#### temporary-read

```bsl
Возврат ПолучитьИзВременногоХранилища("x");
```

Ожидается ошибка исполнения: `unknown function "ПолучитьИзВременногоХранилища"`.

#### bsp-template

```bsl
Возврат СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку("%1", "A");
```

Ожидается ошибка исполнения: `«СтроковыеФункцииКлиентСервер» не заполнено`.

#### bsp-value

```bsl
Возврат ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Неопределено, "Имя");
```

Ожидается ошибка исполнения: `«ОбщегоНазначения» не заполнено`.

#### query

Контекст: CLI eval с `--sqlite`.

```bsl
З = Новый Запрос(); З.Текст = "ВЫБРАТЬ 7 КАК Число"; Р = З.Выполнить().Выгрузить(); Возврат Р[0].Число;
```

Результат JSON: `7`.

#### query-constructor-text

Контекст: CLI eval с `--sqlite`.

```bsl
З = Новый Запрос("ВЫБРАТЬ 7 КАК Число"); Возврат З.Текст;
```

Результат JSON: `""`.

#### bsp-language

```bsl
Возврат ОбщегоНазначения.КодОсновногоЯзыка();
```

Ожидается ошибка исполнения: `«ОбщегоНазначения» не заполнено`.

#### bsp-module

```bsl
Возврат ОбщегоНазначения.ОбщийМодуль("Тест");
```

Ожидается ошибка исполнения: `«ОбщегоНазначения» не заполнено`.

#### bsp-subsystem

```bsl
Возврат ОбщегоНазначения.ПодсистемаСуществует("Тест");
```

Ожидается ошибка исполнения: `«ОбщегоНазначения» не заполнено`.

Привязка обработки к объекту и покрытие API `ПодключаемыеКоманды` остаются пробелом по [#1479](https://github.com/ivanarama/onebase/issues/1479) и плану 135; внешний контур обработок сам по себе не является этим API. Непроверенные подсистемы, менеджеры, транзакционные окружения и редкие методы разбираются отдельно по плану 179. Эта матрица не заявляет совместимость произвольной конфигурации или библиотеки БСП.
