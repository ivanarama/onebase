# Параметры отчёта из перечисления

Статус: Draft, реализация и SDK проверяются.

Параметр `type: enum:ИмяПеречисления` использует штатное перечисление
конфигурации. Форма отчёта показывает выбор из метаданных в объявленном
порядке; подписи берутся из перевода значения для текущего языка. В запрос,
REST и ссылки выгрузки передаётся каноническое имя значения, а не его подпись.
Копировать `options` в каждый отчёт не требуется.

```yaml
params:
  - name: ФормаОбслуживания
    type: enum:ФормыОбслуживания
    default: Выезд
```

Отсутствующий параметр получает умолчание. Явно очищенный выбор остаётся
пустым и не заменяется умолчанием. Текущее допустимое значение сохраняется
на форме результата. Неизвестное перечисление и недопустимое непустое
значение останавливают запуск или выгрузку; свободный текст не становится
новым элементом перечисления. Пустой выбор разрешён.

Контракт распространяется на штатную форму отчёта, обычный и табличный
результат интеграционной линии, Excel/PDF, фоновые выгрузки и REST v2.
Ссылочные параметры сохраняют штатный выбор, ACL/RLS, исторические значения
и объявленный порядок каталога. Правки прикладных YAML не требуются.
