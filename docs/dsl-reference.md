# Справочник встроенного языка OneBase

Полный список того, что понимает платформа: **169 функций**, **159 методов
объектов**, **18 конструкций языка** и **37 элементов языка запросов**.

Файл сгенерирован командой `onebase langref` из реестра `internal/dsl/langref` —
того же, что питает автодополнение и подсказки в конфигураторе. Разойтись с
платформой он не может: сверка живёт в тестах, и правка реестра без
перегенерации этого файла роняет сборку.

Язык русскоязычный и **регистронезависимый**: `Сообщить`, `СООБЩИТЬ` и
`сообщить` — одно и то же. У большинства имён есть английские синонимы, они
указаны у каждой записи.

> Как читать сигнатуру: `Функция(Обязательный, [Необязательный])`.
> Квадратные скобки — параметр можно не передавать.

#### ВебСокет

```
ВебСокет.ИмяШлюза.Отправить(Строка) | .Подключён()
```

Глобальный объект исходящих WebSocket-соединений приёмки (шлюз intake с transport: ws, план 120). Отправить(Строка) пишет текстовое сообщение в живое соединение; формат — дело конфигурации, объект сериализуйте заранее (ЗначениеВJSON). Гарантий доставки нет: обрыв или неподнятое соединение — исключение сразу (перехватывается Попытка/Исключение), буфера и повтора нет. Подключён() — Булево. Входящие сообщения сюда не относятся: их принимает обработчик шлюза (процедура Обработать) через приёмку с идемпотентностью и карантином.

```
Если ВебСокет.СобытияОбмена.Подключён() Тогда
    ВебСокет.СобытияОбмена.Отправить(ЗначениеВJSON(Данные));
КонецЕсли;
```

Синонимы: `WebSocket`

#### РегистрыСведений

```

```

Глобальный объект доступа к регистрам сведений. СоздатьМенеджерЗаписи() отдаёт менеджер записи: значения измерений и ресурсов присваиваются как реквизиты, дальше Записать/Прочитать/Удалить/Выбран. Период обязателен у периодического регистра и запрещён у непериодического. ```
Запись = РегистрыСведений.СостояниеУзлов.СоздатьМенеджерЗаписи();
Запись.Узел = Узел;
Запись.Состояние = "Готов";
Запись.Записать();
```

Синонимы: `InfoRegisters`

#### РегламентныеЗадания

```
РегламентныеЗадания.Запустить("ИмяЗадания") | .Прогон(ИдПрогона)
```

Запуск регламентного задания по требованию, не дожидаясь расписания (план 123). Запустить(Имя) возвращает идентификатор прогона и сразу отдаёт управление — задание работает в фоне; ожидания завершения нет, сессия однопоточная. Прогон(Ид) возвращает Структуру с полями Задание, Статус, Начало, Конец, ДлительностьМс, Ошибка, Вывод — либо Неопределено, если журнал такого прогона не помнит. Статус: running, success, error, timeout, interrupted. Параллелизма нет: одно задание в один момент выполняется один раз, попытка запустить занятое даёт перехватываемое Попытка/Исключение исключение «уже выполняется» — это штатная гонка с запуском по расписанию. Запуск внутри транзакции запрещён, в том числе из ОбработкаПроведения: запускайте после записи. Прикладной результат задание возвращает через данные (регистр сведений), а не через журнал прогонов; Вывод — это склейка Сообщить() задания, и она может быть большой. Задание, у которого выключено расписание (enabled: false), запускается — это штатный способ держать «задание по требованию». Если ждёте завершения опросом Прогон(Ид), держите собственный предел ожидания: прогон, прерванный жёстким завершением процесса, остаётся в статусе running.

#### ФоновыеЗадания

```
ФоновыеЗадания.Поставить("ИмяЗадания"[, Параметры][, Ключ]) | .Задача(Ид) | .Отменить(Ид) | .Глубина([Статус])
```

Очередь фоновых заданий с пулом исполнителей (план 130). В отличие от РегламентныеЗадания.Запустить даёт ПАРАЛЛЕЛИЗМ: одно и то же задание исполняется многими исполнителями сразу, каждый со своими параметрами. Поставить(Имя, Параметры, Ключ) возвращает идентификатор задачи; Параметры — Структура или Соответствие со скалярами (строка, число, булево, дата), они перекрывают params задания поимённо. Ключ — идемпотентность: пока задача с этим ключом ждёт или исполняется, повторная постановка не плодит дубль, а возвращает идентификатор живой задачи. Задача(Ид) возвращает Структуру с полями Задание, Статус, Ключ, Попытки, МаксПопыток, Создана, Начало, Конец, ДоступнаС, ДлительностьМс, Исполнитель, Ошибка, Вывод, Параметры — либо Неопределено, если очередь такой задачи не помнит. Статус: pending, running, done, dead (попытки исчерпаны), cancelled. Отменить(Ид) снимает задачу из очереди или просит исполнителя прерваться. Глубина([Статус]) — сколько задач в статусе (по умолчанию pending); полезно продюсеру, чтобы не заваливать очередь новым кругом. Ставить задачу МОЖНО внутри транзакции, в том числе из ОбработкаПроведения: задача станет видимой исполнителю после коммита, а откат снимет её вместе с данными. Доставка at-least-once: задача, чей исполнитель умер жёстко, вернётся в очередь по истечении аренды и будет исполнена ещё раз — обработка обязана быть идемпотентной. На SQLite исполнитель всегда один (там одно соединение на базу); пул на 16–32 требует PostgreSQL.

**Возвращает:** строка (идентификатор задачи) | структура | Неопределено | булево | число

```
Для Каждого Узел Из Узлы Цикл
    ФоновыеЗадания.Поставить("ОбменСУзлом", Новый Структура("Узел", Узел.Код), "обмен-" + Узел.Код);
КонецЦикла;
Сообщить("Ждут исполнителя: " + ФоновыеЗадания.Глубина());
```

Синонимы: `BackgroundJobs`

## Конструкции языка

#### Возврат

```
Возврат [<выражение>];
```

Завершает выполнение процедуры или возвращает значение из функции.

Синонимы: `Return`

#### Для … По … Цикл … КонецЦикла

```
Для <Счётчик> = <Начало> По <Конец> Цикл
  ...
КонецЦикла;
```

Числовой цикл: счётчик увеличивается от Начало до Конец включительно с шагом 1.

```
Для и = 1 По 10 Цикл
  Сообщить(и);
КонецЦикла;
```

Синонимы: `For`, `To`, `Do`, `EndDo`

#### Для Каждого … Из … Цикл … КонецЦикла

```
Для Каждого <Элемент> Из <Коллекция> Цикл
  ...
КонецЦикла;
```

Перебирает все элементы коллекции (массив, результат запроса и т.п.).

```
Для Каждого Стр Из Таблица Цикл
  Сообщить(Стр.Наименование);
КонецЦикла;
```

Синонимы: `For`, `Each`, `In`, `Do`, `EndDo`

#### Если … Тогда … КонецЕсли

```
Если <условие> Тогда
  ...
[ИначеЕсли <условие> Тогда
  ...]
[Иначе
  ...]
КонецЕсли;
```

Условное ветвление. Ветки ИначеЕсли и Иначе необязательны; можно использовать любое количество ИначеЕсли.

```
Если Сумма > 0 Тогда
  Сообщить("плюс");
ИначеЕсли Сумма < 0 Тогда
  Сообщить("минус");
Иначе
  Сообщить("ноль");
КонецЕсли;
```

Синонимы: `If`, `Then`, `ElseIf`, `Else`, `EndIf`

#### И

```
<выражение> И <выражение>
```

Логический оператор «и» (конъюнкция): Истина, если оба операнда истинны.

Синонимы: `And`

#### ИЛИ

```
<выражение> ИЛИ <выражение>
```

Логический оператор «или» (дизъюнкция): Истина, если хотя бы один операнд истинен.

Синонимы: `Or`

#### Истина

```
Истина
```

Булев литерал «истина» (логическое значение Да/True).

Синонимы: `True`

#### Ложь

```
Ложь
```

Булев литерал «ложь» (логическое значение Нет/False).

Синонимы: `False`

#### НЕ

```
НЕ <выражение>
```

Логический оператор отрицания: инвертирует булево значение операнда.

Синонимы: `Not`

#### Неопределено

```
Неопределено
```

Специальное значение, означающее отсутствие присвоенного значения (аналог null).

Синонимы: `Undefined`

Новый <ТипОбъекта>([<параметры>])
```

Создаёт новый экземпляр встроенного типа, например Новый Массив или Новый ТаблицаЗначений.

#### Пока … Цикл … КонецЦикла

Пока <условие> Цикл
  ...

```

КонецПроцедуры;
```

Объявляет именованную процедуру (не возвращает значение). Параметры можно передавать по значению (Знач); модификатор Экспорт делает процедуру доступной извне модуля.

```
Процедура Рассчитать(Знач Сумма)
  Сообщить(Сумма);
КонецПроцедуры;
```

Синонимы: `Procedure`, `EndProcedure`

#### Функция … КонецФункции

```
Функция <Имя>([Знач] <параметр>, ...) [Экспорт]
  ...
  Возврат <значение>;
КонецФункции;
```

Объявляет именованную функцию, возвращающую значение оператором Возврат. Параметры и Экспорт — аналогично Процедуре.

```
Функция Сложить(А, Б)
  Возврат А + Б;
КонецФункции;
```

Синонимы: `Function`, `EndFunction`

---

## Язык запросов

#### В

```
<поле> В (&Параметр)
```

Проверяет вхождение значения в список или массив-параметр. Массив &Param разворачивается в перечень плейсхолдеров.

```
ГДЕ Склад В (&СписокСкладов)
```

Синонимы: `IN`

#### ВНУТРЕННЕЕ СОЕДИНЕНИЕ

```
ВНУТРЕННЕЕ СОЕДИНЕНИЕ <источник> ПО <условие>
```

Внутреннее соединение: только строки, удовлетворяющие условию с обеих сторон.

```
ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Контрагенты КАК К ПО К.Ссылка = д.Контрагент
```

Синонимы: `INNER JOIN`

#### ВОЗР

```
УПОРЯДОЧИТЬ ПО <поле> ВОЗР
```

Направление сортировки по возрастанию (применяется в УПОРЯДОЧИТЬ ПО).

```
УПОРЯДОЧИТЬ ПО Дата ВОЗР
```

Синонимы: `ASC`

#### ВЫБОР

```
ВЫБОР КОГДА <условие> ТОГДА <значение> [ИНАЧЕ <значение>] КОНЕЦ
```

Условное выражение в запросе (аналог CASE/WHEN/THEN/ELSE/END в SQL).

```
ВЫБОР КОГДА Количество > 0 ТОГДА 'Есть' ИНАЧЕ 'Нет' КОНЕЦ КАК Наличие
```

Синонимы: `CASE`

#### ВЫБРАТЬ

```
ВЫБРАТЬ [РАЗЛИЧНЫЕ] <поля> ИЗ <источник>
```

Открывает запрос; перечисляет поля для выборки. РАЗЛИЧНЫЕ исключает дубли строк. Ссылочное поле (Контрагент, Склад) приходит в результат представлением — наименованием справочника или номером документа, — поэтому сравнивать по нему объекты нельзя: представления повторяются. Идентификатор выбирают явно: свой — ВЫБРАТЬ Ссылка, чужой — ВЫБРАТЬ Склад.Ссылка КАК ИдСклада. Полученный UUID — строка без методов; объект по нему даёт Справочники.X.НайтиПоИдентификатору(...).

```
ВЫБРАТЬ Номенклатура, СУММА(Количество) КАК КолвоИтог ИЗ РегистрНакопления.ОстаткиТоваров
```

Синонимы: `SELECT`

#### ГДЕ

```
ГДЕ <условие>
```

Фильтрует строки источника до группировки; условие может включать &параметры.

```
ГДЕ Склад = &Склад
```

Синонимы: `WHERE`

#### ЕСТЬ

```
<поле> ЕСТЬ ПУСТО
```

Проверяет, является ли значение NULL (ЕСТЬ ПУСТО → IS NULL).

```
ГДЕ Номенклатура ЕСТЬ ПУСТО
```

Синонимы: `IS`

#### ЕстьNULL

```
ЕстьNULL(Значение, ЗначениеЕслиNULL)
```

Подставляет второе значение, если первое NULL (SQL COALESCE). Нужен после левых соединений и виртуальных таблиц остатков.

```
ВЫБРАТЬ ЕстьNULL(Остатки.КоличествоОстаток, 0) КАК Кол
```

Синонимы: `ISNULL`, `COALESCE`

#### И

```
<условие1> И <условие2>
```

Логическое И — оба условия должны быть истинны.

```
ГДЕ Склад = &Склад И Дата >= &НачДата
```

Синонимы: `AND`

#### ИЗ

```
ИЗ <ТипИсточника>.<Имя>[.ВиртуальнаяТаблица(...)]
```

Задаёт источник данных: справочник, документ, регистр или виртуальная таблица.

```
ИЗ Справочник.Номенклатура
```

Синонимы: `FROM`

#### ИЛИ

```
<условие1> ИЛИ <условие2>
```

Логическое ИЛИ — хотя бы одно условие должно быть истинно.

```
ГДЕ Склад = &Склад1 ИЛИ Склад = &Склад2
```

Синонимы: `OR`

#### ИМЕЯ

```
ИМЕЯ <условие на агрегат>
```

Фильтрует сгруппированные строки по условию над агрегатными функциями.

```
ИМЕЯ СУММА(Количество) > 0
```

Синонимы: `ИМЕЮЩИЕ`, `HAVING`

#### КАК

```
<выражение> КАК <Псевдоним>
```

Присваивает псевдоним полю или подзапросу в результате выборки.

```
СУММА(Количество) КАК КолвоИтог
```

Синонимы: `AS`

#### КОЛИЧЕСТВО()

```
КОЛИЧЕСТВО(<поле>|*)
```

Агрегатная функция — возвращает количество строк (или ненулевых значений поля) в группе.

```
КОЛИЧЕСТВО(*) КАК ЧислоЗаписей
```

Синонимы: `COUNT`

#### ЛЕВОЕ СОЕДИНЕНИЕ

```
ЛЕВОЕ СОЕДИНЕНИЕ <источник> ПО <условие>
```

Левое внешнее соединение: все строки левого источника, плюс совпавшие строки правого.

```
ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Склады КАК Скл ПО Скл.Ссылка = рег.Склад
```

Синонимы: `LEFT JOIN`

#### МАКСИМУМ()

```
МАКСИМУМ(<поле>)
```

Агрегатная функция — возвращает максимальное значение поля в группе.

```
МАКСИМУМ(Дата) КАК ПоследняяДата
```

Синонимы: `MAX`

#### МЕЖДУ

```
<поле> МЕЖДУ <начало> И <конец>
```

Проверяет, входит ли значение в указанный диапазон, включая обе границы.

```
ГДЕ Дата МЕЖДУ &ДатаНачала И &ДатаОкончания
```

Синонимы: `BETWEEN`

#### МИНИМУМ()

```
МИНИМУМ(<поле>)
```

Агрегатная функция — возвращает минимальное значение поля в группе.

```
МИНИМУМ(Цена) КАК МинЦена
```

Синонимы: `MIN`

#### НЕ

```
НЕ <условие>
```

Логическое отрицание условия.

```
ГДЕ НЕ Склад = &Склад
```

Синонимы: `NOT`

#### Обороты()

```
РегистрНакопления.<Имя>.Обороты(&Начало, &Конец, <Периодичность>, <Условие>)
```

Виртуальная таблица оборотов регистра накопления за период. Третий аргумент — периодичность (День/Неделя/Месяц/Квартал/Год/Запись); четвёртый — условие фильтра. Ресурсы получают суффиксы Приход/Расход/Оборот.

```
ИЗ РегистрНакопления.ОстаткиТоваров.Обороты(&НачДата, &КонДата)
```

Синонимы: `Turnovers`

#### Обороты() [РегБухгалтерии]

```
РегистрБухгалтерии.<Имя>.Обороты(&Начало, &Конец, <Условие>)
```

Виртуальная таблица оборотов по счетам регистра бухгалтерии за период; ресурсы получают суффиксы _дт и _кт. Третий аргумент — условие фильтра.

```
ИЗ РегистрБухгалтерии.Основной.Обороты(&НачДата, &КонДата)
```

Синонимы: `AccountTurnovers`

#### ОБЪЕДИНИТЬ

```
ОБЪЕДИНИТЬ [ВСЕ]
```

Объединяет результаты нескольких запросов; ВСЕ сохраняет дубли.

```
ВЫБРАТЬ Код ИЗ Справочник.А ОБЪЕДИНИТЬ ВСЕ ВЫБРАТЬ Код ИЗ Справочник.Б
```

Синонимы: `UNION`

#### Остатки()

```
РегистрНакопления.<Имя>.Остатки(&НаДату, <Условие>)
```

Виртуальная таблица остатков регистра накопления на указанную дату; поля-ресурсы получают суффикс Остаток. Второй аргумент — необязательное условие фильтра.

```
ИЗ РегистрНакопления.ОстаткиТоваров.Остатки(&НаДату)
```

Синонимы: `Balances`

#### Остатки() [РегБухгалтерии]

```
РегистрБухгалтерии.<Имя>.Остатки(&НаДату, <Условие>)
```

Виртуальная таблица остатков по счетам регистра бухгалтерии на дату; ресурсы получают суффиксы _дт, _кт и Остаток. Второй аргумент — условие фильтра по счёту или субконто.

```
ИЗ РегистрБухгалтерии.Основной.Остатки(&НаДату)
```

Синонимы: `AccountBalances`

#### ОстаткиИОбороты()

```
РегистрНакопления.<Имя>.ОстаткиИОбороты(&Начало, &Конец, <Условие>)
```

Виртуальная таблица остатков и оборотов регистра накопления: начальный остаток, приход, расход и конечный остаток за период.

```
ИЗ РегистрНакопления.ОстаткиТоваров.ОстаткиИОбороты(&НачДата, &КонДата)
```

Синонимы: `BalancesAndTurnovers`

#### ПЕРВЫЕ

```
ВЫБРАТЬ [РАЗЛИЧНЫЕ] ПЕРВЫЕ <N> <поля>
```

Ограничивает простой запрос первыми N строками (SQL LIMIT). Сочетается с РАЗЛИЧНЫЕ и УПОРЯДОЧИТЬ ПО; в ветвях ОБЪЕДИНИТЬ и подзапросах пока отклоняется явно. N = 0 допустимо и даёт пустой результат (как в 1С), отрицательное — ошибка.

```
ВЫБРАТЬ ПЕРВЫЕ 10 Наименование ИЗ Справочник.Номенклатура УПОРЯДОЧИТЬ ПО Наименование
```

Синонимы: `TOP`

#### ПОЛНОЕ СОЕДИНЕНИЕ

```
ПОЛНОЕ СОЕДИНЕНИЕ <источник> ПО <условие>
```

Полное внешнее соединение: все строки обоих источников; несовпавшие поля заполняются NULL.

```
ПОЛНОЕ СОЕДИНЕНИЕ Справочник.Склады КАК С ПО С.Ссылка = рег.Склад
```

Синонимы: `FULL JOIN`

#### ПРАВОЕ СОЕДИНЕНИЕ

```
ПРАВОЕ СОЕДИНЕНИЕ <источник> ПО <условие>
```

Правое внешнее соединение: все строки правого источника, плюс совпавшие строки левого.

```
ПРАВОЕ СОЕДИНЕНИЕ Справочник.Номенклатура КАК Н ПО Н.Ссылка = рег.Номенклатура
```

Синонимы: `RIGHT JOIN`

#### ПУСТО

```
ЕСТЬ ПУСТО | НЕ ЕСТЬ ПУСТО
```

Ключевое слово NULL в языке запросов; используется с ЕСТЬ для проверки на пустое значение.

```
ГДЕ Склад ЕСТЬ ПУСТО
```

Синонимы: `NULL`

#### РАЗЛИЧНЫЕ

```
ВЫБРАТЬ РАЗЛИЧНЫЕ <поля>
```

Убирает дублирующиеся строки результата запроса.

```
ВЫБРАТЬ РАЗЛИЧНЫЕ Склад ИЗ РегистрНакопления.ОстаткиТоваров
```

Синонимы: `DISTINCT`

#### СГРУППИРОВАТЬ ПО

```
СГРУППИРОВАТЬ ПО <поле1>[, <поле2>...]
```

Группирует строки по указанным полям; обязательно при использовании агрегатных функций.

```
СГРУППИРОВАТЬ ПО Номенклатура, Склад
```

Синонимы: `GROUP BY`

#### СРЕДНЕЕ()

```
СРЕДНЕЕ(<поле>)
```

Агрегатная функция — возвращает среднее арифметическое значений поля в группе.

```
СРЕДНЕЕ(Сумма) КАК СредняяСумма
```

Синонимы: `AVG`

#### СрезПервых()

```
РегистрСведений.<Имя>.СрезПервых(&НаДату, <Условие>)
```

Виртуальная таблица среза первых записей периодического регистра сведений начиная с указанной даты.

```
ИЗ РегистрСведений.ЦеныНоменклатуры.СрезПервых(&НаДату)
```

Синонимы: `FirstSlice`

#### СрезПоследних()

```
РегистрСведений.<Имя>.СрезПоследних(&НаДату, <Условие>)
```

Виртуальная таблица среза последних записей периодического регистра сведений на указанную дату. Для непериодических регистров дата игнорируется.

```
ИЗ РегистрСведений.ЦеныНоменклатуры.СрезПоследних(&НаДату)
```

Синонимы: `LastSlice`

#### СУММА()

```
СУММА(<поле>)
```

Агрегатная функция — возвращает сумму значений поля в группе.

```
СУММА(Количество) КАК ОбщееКоличество
```

Синонимы: `SUM`

#### УБЫВ

```
УПОРЯДОЧИТЬ ПО <поле> УБЫВ
```

Направление сортировки по убыванию (применяется в УПОРЯДОЧИТЬ ПО).

```
УПОРЯДОЧИТЬ ПО Сумма УБЫВ
```

Синонимы: `DESC`

#### УПОРЯДОЧИТЬ ПО

```
УПОРЯДОЧИТЬ ПО <поле> [ВОЗР|УБЫВ][, ...]
```

Сортирует результат запроса по одному или нескольким полям.

```
УПОРЯДОЧИТЬ ПО Сумма УБЫВ
```

Синонимы: `ORDER BY`
