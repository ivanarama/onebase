# Переносимый режим OneBase

Запуск с `--portable` хранит служебные данные OneBase в `.onebase` рядом
с исполняемым файлом:

```powershell
.\onebase-gui.exe --portable
```

Для консольной сборки работает тот же флаг:

```sh
./onebase --portable start
```

Каталог определяется по расположению программы, независимо от рабочей папки
ярлыка или терминала. Относительные аргументы команд в этом режиме тоже
считаются от каталога программы. Например:

```sh
./onebase --portable migrate --project project --sqlite data/example.db
./onebase --portable ibases add --name "Пример" --source file --path project --sqlite data/example.db
```

Пример комплекта:

```text
OneBase/
  onebase-gui.exe
  project/
  data/example.db
  .onebase/
    ibases.yaml
    files/
    backups/
    logs/
    workspace/
    browser-profiles/
    state/
    updates/
```

Список баз, настройки лаунчера, вложения с расположением по умолчанию,
журналы, рабочие копии конфигураций, резервные копии и состояние обновлений
используют этот каталог. Встроенный WebView также получает локальный профиль;
внешний системный браузер управляет собственными данными самостоятельно.
Дочерние процессы баз, миграций и окон наследуют переносимый корень.
`HOME`, `USERPROFILE`, `APPDATA` и `LOCALAPPDATA` программы не подменяют.

Лаунчер сохраняет пути к проектам и SQLite-файлам **внутри комплекта**
относительными, а при открытии разрешает их от нового расположения программы.
Для переноса закройте базы и лаунчер, дождитесь завершения обновлений и
скопируйте **всю папку**, включая `.onebase`. Затем запускайте программу
с `--portable` на новом месте. Нельзя копировать работающий SQLite-файл
как обычный закрытый файл: для работающей базы используйте резервное копирование.

Флаг сам не копирует прежние базы и пользовательский профиль. Для существующей
базы перенесите её и вложения подходящим резервным комплектом и добавьте базу
в переносимый лаунчер. Пути вне комплекта остаются абсолютными. Абсолютные
пути, явно заданные в настройках конфигурации или внешних переменных окружения,
автоматически не переписываются. Внешние PostgreSQL/S3-серверы, системные
зависимости GUI и отдельно заданные ключи шифрования требуют своей настройки.

Каталог программы должен быть доступен для записи. При недоступной `.onebase`
запуск завершается с ошибкой; скрытого перехода в обычный пользовательский
профиль нет. Без `--portable` и без унаследованного переносимого окружения
сохраняется обычное расположение `~/.onebase`.

На Windows путь профиля WebView должен занимать не более 259 кодовых единиц
UTF-16. Ограничение проверяется и для общего профиля, и для явно заданного
`ONEBASE_WEBVIEW_PROFILE`. При превышении запуск завершается с ошибкой:
переместите комплект в каталог с более коротким путём.

Переносимый режим предназначен для локальной работы и разработки. Установка
системной службы в нём отклоняется: для службы используйте обычную установку.
`ONEBASE_PORTABLE_ROOT` передаёт абсолютный корень между процессами OneBase;
для обычного запуска достаточно флага. `--portable=false` явно отключает
унаследованный переносимый корень.
