# Универсальные отборы результата отчёта — контракт Draft

Владелец platform2, передача platform от 16.11.2026 (файл1703). Это целевой контракт и ограничения незавершённой реализации, не готовая поставка.

Выбор разрешённой колонки результата, применимого оператора и типизированного значения; несколько условий AND. Сохранение в пользовательском варианте. Одинаковое действие HTML/Excel/PDF/background/REST. Отбор исходных значений до лимита строк, UUID-подписей, пользовательских группировок/итогов и пагинации. Базовый запрос определяет исходный набор; внутренние SQL-агрегаты не заменяются условием по сырым строкам.

Descriptor восстанавливается сервером из ProjectionColumn.Path, SourceOccurrences и метаданных источника. Алиас/preset/runtime-тип не доказывают lineage. Только однозначные прямые поля известного типа и UUID ссылок. Дубли выходных ключей, wildcard без proof, неизвестные выражения, UNION/подзапросы и произвольные DSL/result_proc строки исключаются из списка; подделанный запрос отвергается. Полное покрытие СКД не обещается. Если исходный SQL содержит FIRST/LIMIT, нельзя незаметно отбирать уже обрезанный набор.

Единая policy platform3: metadata.Field.PII, обязательный hide независимо admin/full. Исходные label fields защищённой сущности исключены; ref UUID и переход сохраняются. Обычная ролевая маска также запрещает отбор. Подключение access/report_output.go только после опубликованных сигнатур/SHA; политики по именам Телефон/Адрес не дублировать. Карточки неизменны.

Операторы: строка eq/ne/contains, enum eq/ne, число/дата eq/ne/gt/ge/lt/le, bool/reference UUID eq/ne. Значения проверяет сервер, decimal без потери точности. NULL отдельно от пустой строки/false/0. Имена/операторы/значения/preset, повреждённый JSON, превышение числа условий дают явную ошибку. Значения SQL — только позиционные параметры. Пустой набор условий сохраняет поведение.

Точки подключения: новые report_result_filter*.go; план до RunLimit в handlers_reports.go, export_jobs.go, API report handler; report_settings.go сохранение/чтение; узкий filters-блок templates.go и отдельный controller asset. Если нужен compiler proof, отдельные query/result_filter*.go без ослабления существующей защиты. Уровни/итоги/фон принадлежат platform, параметры/output policy — platform3.

Публичные HTTP/API проверки: типы/AND, alias/неоднозначный JOIN, PII/admin/rename, UUID без сырой подписи, подделанные условия/preset, совпадение HTML/Excel/PDF/background/API, совпадение за исходным row limit, итоги и переходы. SQL — dbtest.ForEachDialect SQLite/owned PG. Тяжёлые/native только общей пачкой примерно раз в3ч через общий замок, максимум два одновременно.
